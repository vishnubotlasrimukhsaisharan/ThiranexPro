# Nexa

The second Thiranex responsive website concept: a productivity workspace landing page.

## Implementation details

- CSS Grid handles the dashboard, feature cards, workflow, and responsive page layouts.
- Flexbox aligns navigation, controls, cards, and compact components.
- Mobile-first responsive breakpoints adapt the design for phone, tablet, and desktop sizes.
- CSS custom properties power the light/dark theme, which is toggled with an accessible control and persisted in local storage.
