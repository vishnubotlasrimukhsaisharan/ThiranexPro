# Skyline Weather Dashboard

A live weather dashboard that uses the Fetch API and async/await to retrieve city coordinates and current/five-day weather data from Open-Meteo.

## Features

- Search weather by city name
- Live temperature, feels-like temperature, humidity, wind speed, precipitation, UV index, sunrise, and sunset
- Five-day forecast parsed from nested API response objects
- Loading, empty, invalid-city, and network error states
- Dynamic forecast DOM rendering
- Responsive accessible dashboard
