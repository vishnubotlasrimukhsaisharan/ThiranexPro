# Thiranex

An accessible, responsive landing page for Thiranex, built with semantic HTML, modern CSS, and lightweight JavaScript.

## Included

- Semantic page landmarks and heading hierarchy
- Keyboard-friendly navigation and contact form
- ARIA labels, live status messaging, and skip link
- SEO metadata and Open Graph tags
- Responsive layout with reduced-motion support

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.
